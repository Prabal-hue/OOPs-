# Python OOPs Journey 🚀

Welcome to my repository for learning and practicing **Object-Oriented Programming (OOP) in Python**! This space documents my progress as I transition from procedural programming to writing modular, reusable, and maintainable object-oriented code.

---

## 📚 Topics Covered

Here are the core OOP pillars and concepts I am exploring and implementing:

*   **Classes and Objects**: Blueprints for creating objects and instantiating them.
*   **The `__init__` Constructor**: Initializing object attributes.
*   **Attributes & Methods**: Instance variables, class variables, and different types of methods (`@staticmethod`, `@classmethod`).
*   **The Four Pillars of OOP**:
    *   *Inheritance*: Reusing code by creating child classes from parent classes.
    *   *Encapsulation*: Hiding internal state using private/protected modifiers (`_` and `__`).
    *   *Polymorphism*: Using unified interfaces for different data types/classes (Method Overriding & Duck Typing).
    *   *Abstraction*: Hiding complex implementation details using abstract base classes (`abc` module).
*   **Magic/Dunder Methods**: Customizing object behavior (e.g., `__str__`, `__repr__`, `__len__`).
